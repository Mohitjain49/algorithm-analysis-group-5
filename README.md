# Minimax Tic-Tac-Toe AI

Tic-Tac-Toe against an AI that never loses, with live stats that show how
Minimax and Alpha-Beta Pruning differ. Live demo: tictactoe.mohit-jain.com

## Features
- Minimax and Alpha-Beta Pruning implemented from scratch
- Per-move metrics: nodes visited, execution time, branches pruned
- Alpha-Beta cut node visits by up to 75%
- Layered backend: rules engine, AI algorithms, session manager, REST API
- Web frontend with live scoreboard and algorithm toggle

## Tech
Python, Vue, REST API, HTML/CSS/JavaScript, GitHub Actions
